# Reports and compliance

Evidence for people who were not in the pull request: a security lead, an auditor, a customer questionnaire.

## Reports

Build a report from a period, a set of repositories and a grouping, then export it as PDF or CSV. Save it as a schedule to have it sent every week or month.

Open findings are mapped to the OWASP API Top 10 and to CWE, using the reference each rule declares.

## Audit log

Every policy change, triage decision and merge override is recorded, with who did it and when. The log cannot be edited and can be exported at any time.
