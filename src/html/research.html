Method

Corpus: public repositories self-identifying as AI-generated or vibe-coded applications. Each was scanned once with the OAuthLint version noted above, using the default rule pack and no suppressions. Findings were counted as reported; nothing was hand-filtered in or out.

Figures are provisional and updated with each snapshot. The dataset description and scripts live in the repository. To reproduce them:

$ npx oauthlint bench
