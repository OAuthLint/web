We read the diff, not your codebase.

OAuthLint Cloud is built for teams who will not grant access on trust. This page states exactly what we receive, what we keep, and for how long.

What we receive

  • The files a pull request changes, read for the scan and then discarded
  • Repository names and branch names
  • Commit authors, to attribute findings

What we never do

  • Keep a copy of your repository
  • Keep source code after a scan finishes
  • Train any model on your code

Retention

  • Source: discarded when the scan ends
  • Findings and history: 24 months
  • Audit log: 24 months, exportable at any time

Access control

  • SSO / SAML with Okta, Entra ID and Google Workspace
  • SCIM provisioning and deprovisioning
  • Owner, Admin, Member and Viewer roles

OAuthLint is local-first. Anything that leaves your machine does so because you chose a mode that needs it.
