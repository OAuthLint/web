AI writes working auth code that is quietly unsafe.

It compiles, it passes the tests, and it trusts the wrong token. These are the patterns we see most in AI-generated pull requests.

- jwtVerify(token, key, { issuer })
+ jwtVerify(token, key, { issuer, audience })

- authorize({ client_id, redirect_uri })
